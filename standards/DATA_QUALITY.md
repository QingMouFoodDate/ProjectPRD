# 《轻眸识刻》数据质量规范

> **规范性质**：全系统数据集质量控制最高硬性标准  
> **适用范围**：数据采集、清洗、初筛、标注审核与自动化质检入库全流程

---

## 一、 核心质量底线

真实的高质量数据是深度学习模型的生命线。本项目在数据管理中坚决贯彻两条不可逾越的底线：

1. **零算法伪造与程序脑补**：严禁任何算式生成、取模循环、随机填充或程序脑补标签；所有清单中的文字必须 100% 来源于实物包装肉眼确凿可见的信息；
2. **强制单张原图无损审阅**：永久禁止将多张图片拼合成 4x4、2x2 等 Grid 形式粗审；严禁编写拼图脚本；审阅必须一次一张打开本地原图，全分辨率逐像素细查画面四个边缘角落与打码主体。

---

## 二、 标准基准集排除规则

为防止带偏小目标检测网络先验或破坏标准基准集的真实分布，凡出现以下任一特征不得进入标准基准集。若用于鲁棒性研究，必须单独标记为干扰样本：

1. **人为手绘涂鸦与标记圈**：手工用红笔、记号笔、手机画图圈出的红圈、椭圆、指认箭头和批注线等；
2. **自媒体营销大字幕与横幅**：短视频截屏中横贯画面的醒目营销大字（如“注意看”、“临期食品能不能买”）、大标题、大表情包遮挡；
3. **电商广告图与印码设备展示**：纯白底渲染电商产品图、手动打码机/喷码机设备本身的商品广告宣传图；
4. **非食品预包装**：纯五金配件、工业用盐、医用耗材、日化香水、药品药盒、保鲜袋盒等非食品流通品；
5. **零算法伪造与程序脑补**：未拍到或未看清字段必须标注为 `null` 或直接剔除，严禁程序推导伪造；
6. **完全无打码或严重缺损**：整图仅有配料表文字而无实物打码；关键日期数字缺失被严重截断；打码区域被反光完全吞噬呈死白一片不可辨识。

---

## 三、 四项生活环境平衡容差标准

兼顾生活实况与组员采集积极性，在守住真实底线的前提下，实施实用平衡容差：

1. **微小角标与相机微水印容限**：画面边缘角落存在不侵入食品包装主体、不触碰遮挡打码区域的单侧极微小平台角标或手机拍照时间水印角标允许保留；全屏半透明防盗水印与正中央居中大水印坚决淘汰；
2. **光影与金属塑料曲面反光容限**：易拉罐金属曲面、塑料袋包装褶皱处的自然轻微反光或漫反射，只要核心日期数字关键笔画清晰可辨、整体字意无歧义即可通过；反光强白斑覆盖并融毁核心笔画坚决淘汰；
3. **单排独立工业打码标注容限**：真实实拍中，若包装上仅印有唯一一处工整清晰打码数字（如易拉罐底 `20240506`、软包封口 `2023.11.12`），且背面注明“见罐底/见封口”，允许采纳并标注为生产日期实体；
4. **真实生活拍摄场景与手持容限**：自然真实手持（手指露在包装边缘）、超市货架实拍、家庭桌面就餐环境等生活实况，只要包装主体居中突出、打码区域对焦清晰即可通过。

## 四、 三大合规采图模式与实体转录

### 1. 三大合规拍摄模式
- **模式 A · 全局说明与局部打码协同**：一张拍全景背标文字（包含品类名、保质期天数或保存条件），一张拍微距打码区域特写，通过多图会话关联；
- **模式 B · 微距打码主体单图**：镜头贴近打码区域，对焦清晰，打码数字占据画面核心视场；
- **模式 C · 条形码与打码辅助关联**：辅助拍摄包装侧面或底面的 EAN-13 商品条形码，与打码图同属一次采集会话。

### 2. 三类核心文本实体
- **生产日期（MFG）**：包含“生产日期”、“PROD DATE”、“MFG”及对应数字串；
- **到期日（EXP）**：包含“保质期至”、“有效日期”、“EXP DATE”、“BEST BEFORE”及对应数字串；
- **保质期说明（SHELF_LIFE）**：包含保质期时长（如“12个月”、“180天”）及常温冷藏要求。

## 五、 自动化质量门禁与验证网关

坚持“先核验、后执行、再复检”原则。每次数据入库或清单变更后，必须通过仓库提供的数据质量校验入口执行检查，具体命令由实现仓库 README 或工程脚本声明：

```bash
<dataset-quality-check-command>
```

### 门禁四大硬性指标
1. **物理文件与清单 100% 吻合**：磁盘文件数量必须与 `manifest.jsonl` 行数严格一致，文件 ID 连续对应；
2. **SHA-256 二进制 0 重复**：严禁同一文件换名入库；
3. **pHash 感知哈希防重校验**：汉明距离防重测试通过（汉明距离 >= 4），严禁通过微小裁剪、缩放二次入库；
4. **实体字段非空与类型合法**：枚举值符合预设规范。
