# 《轻眸识刻》功能规划与范围界定

> **定位**：全系统功能分级与范围规划总表，明确当前阶段大创核心 MVP 边界与长远工业级设计储备。  

---

## 一、 功能层级划分原则

为了防止项目开发过度设计，全系统功能严格遵循三层分级管理：

| 层级 | 定位属性 | 范围界定 | 本阶段处置原则 |
| :--- | :--- | :--- | :--- |
| **T1 · 核心 MVP** | **大创交付底座** | 满足大创申报书承诺的 Web 原型系统在线体验、算法小目标检测、OCR 转录与保质期推导 | **当前集中全力交付，做精做透** |
| **T2 · 工程基准** | **内在质量防线** | 数据集版本管理、SHA-256 / pHash 防重质检脚本、标准接口契约校验 | **已落盘为质量门禁，坚守底线** |
| **T3 · 工业储备** | **长远扩展架构** | 企业级多租户 RBAC 权限、分布式 K8s 算力动态调度、众包任务外包派单、复杂 DAG 流水线 | **保留架构规格作为拓展储备，暂不排期** |

---

## 二、 全系统 9 大模块功能规划总表

| 模块代号与名称 | 包含详细规格 | 核心功能概述 | 层级与当前处置 |
| :--- | :--- | :--- | :--- |
| **01 数据采集** | P0001 ~ P0005 | 采图 SOP 规范、移动端实拍引导、离线队列、采图统计 | **P0001 (T1 必看)**：作为采图规范；其余外包派单延后 |
| **02 数据导入** | P0020 ~ P0024 | 本地图片上传、VOC/YOLO 数据集格式解析、导入预检清洗 | **P0020/P0023 (T1/T2)**：本地上传与哈希防重预检 |
| **03 数据管理** | P0040 ~ P0046 | 样本资产版本挂载、元数据检索、图库画廊预览、数据集导出 | **P0041/P0043 (T1)**：对接 ../data/raw/ 作为基准集 |
| **04 标注中心** | P0060 ~ P0066 | Canvas 交互标注器、类别体系、AI 预标注、字符转写与 OCR 标注 | **P0060/P0065 (T1 必看)**：打码框与字符转写标准 |
| **05 训练平台** | P0080 ~ P0087 | 单机 GPU 训练入口、超参 YAML 驱动、指标监控看板、模型仓库 | **P0083/P0085 (T1/T2)**：单机原生脚本训练与版本记录 |
| **06 流水线** | P0100 ~ P0101 | MLOps 算子编排与执行引擎 | **T3 (工业储备)**：单机脚本直接执行，暂不引入 DAG |
| **07 部署推理** | P0110 ~ P0113 | `/api/v1/ocr/predict` 服务发布、在线试跑、标准 ONNX 模型轻量导出 | **P0111/P0112 (T1 必看)**：Web 在线预测与 ONNX 导出 |
| **08 端接入** | P0120 ~ P0122 | Web 原型系统接入、移动端采集 App 接入、开放 RESTful API 契约 | **P0122 (T1 必看)**：多端统一 API 规范 |
| **09 系统管理** | P0130 ~ P0132 | 用户权限、操作审计日志、系统告警中心 | **T3 (工业储备)**：学生团队无多租户需求，暂不排期 |
