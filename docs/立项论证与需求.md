# 《轻眸识刻》项目立项论证与需求分析

> **文档定位**：南昌大学大学生创新训练计划项目核心论证文档，涵盖业务需求（BRD）与技术可行性分析（MRD），系统阐明立项依据与研发价值

---

## 一、 项目背景与政策刚需

### 1. 政策法规与行业痛点
- **强制合规驱动**：国家卫生健康委员会与市场监督管理总局联合推行的《食品安全国家标准 预包装食品标签通则》(GB 7718-2025) 对食品生产日期与保质期的标示提出严格要求，日期全生命周期可追溯成为流通市场的刚性合规需求；
- **双端痛点盲区**：
  - **C 端消费者痛点**：食品包装生产日期普遍存在点阵喷码断笔、字号微小（常不足 2mm）、印于折角曲面、冷凝水汽反光等问题，肉眼查验困难，尤其对老年群体造成阅读障碍；
  - **B 端商超仓储痛点**：商超便利店与食品仓库面临密集商品的人工翻检，人工成本高且存在漏检风险，临期或过期食品一旦上架将面临严格的食品安全监管处罚。

---

## 二、 核心技术突破与方案对比

针对真实生活实景与工业流通场景，轻眸识刻确立了**“找得到、读得准、判得清、能改进”**的技术攻坚路线：

| 技术维度 | 传统通用 OCR 方案局限 | 轻眸识刻方案设计 |
| :--- | :--- | :--- |
| **小目标检测 (找得到)** | 通用检测网络忽略微小打码（占比 < 1%），易受大面积配料表文字干扰漏检 | 引入浅层高分辨率特征融合层（P2 Head），结合条件去反光增强，定位微距打码框 |
| **微型字符识别 (读得准)** | 工业点阵喷墨断笔严重，通用 OCR 字典庞大，生僻字与字符混淆率高 | 采用专为工业微距文字优化的轻量序列识别网络，搭配严格的工业受限字符字典集 |
| **喷码纠错矩阵** | 缺乏针对点阵断针与粘连特征的纠错机制 | 基于加权 Levenshtein 动态规划，专项探索处理常见断针与闭合混淆字符对 |
| **语义推导引擎 (判得清)** | 仅框选文字，不具备食品保质期语义关联与状态推导能力 | 解析包装标示日期与保质期时长，结合公历进位规则推算截止时间，输出二维客观标示状态 |
| **难例回流闭环 (能改进)** | 离线单向训练，无法沉淀真实边缘难例 | 前台与移动端支持一键纠偏，用户修正样本自动归入待审难例池，支撑增量优化 |

### 方案特性分析
- **本地数据私有可控**：系统采用代码与数据物理解耦架构，全量样本集中管理，支持完全离线部署；
- **微距打码专业定制**：突破通用文字识别在微小打码、断针点阵场景下的鲁棒性瓶颈；
- **轻量化多端适应**：算法网络经剪枝与量化适配，支撑服务端高效推理与端侧轻量运行探索。

## 三、 预期交付成果与转化价值

对齐大创立项申报书承诺目标：
1. **食品包装日期图像样本库**：沉淀覆盖塑料袋、易拉罐、玻璃瓶、纸盒等多种材质与生活环境的高质量基准样本集；
2. **小目标识别与决策算法集**：产出定位检测、点阵 OCR、双向纠错矩阵与语义决策树算法代码，具备完整的实验对比与消融分析报告；
3. **Web 原型系统**：完成集成多图会话、上传识别、Canvas 框选、标示期限推导与难例回流的交互系统，作为项目核心验证载体；
4. **实践拓展成果**：支撑软件著作权申报、高水平学科竞赛作品制作与相关学术论文发表。
