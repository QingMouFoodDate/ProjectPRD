# 《轻眸识刻》项目立项论证与需求分析

> **定位**：南昌大学大学生创新训练计划项目核心论证文档，整合商业价值（BRD）与市场需求（MRD），专供申报书撰写、中期检查与答辩使用。  

---

## 一、 项目背景与政策刚需

### 1. 政策法规与行业痛点
- **强制合规驱动**：国家卫生健康委员会与市场监督管理总局联合推行的《食品安全国家标准 预包装食品标签通则》(GB 7718-2025) 对食品生产日期与保质期的标示提出严格要求，日期全生命周期可追溯成为流通市场的刚性合规需求；
- **双端痛点盲区**：
  - **C 端消费者痛点**：食品包装生产日期普遍存在点阵喷码断笔、字号不足 2mm、印于折角曲面、冷凝水汽反光等问题，肉眼极难辨识，尤其对老年银发群体与视障弱视人群造成严重的阅读障碍；
  - **B 端商超仓储痛点**：商超便利店与食品仓库日均面临数万件商品的人工逐件翻检，人工成本高且极易漏检，临期或过期食品一旦上架将面临严厉的食品安全行政处罚。

---

## 二、 核心技术突破与竞争壁垒

针对真实生活实景与工业流通场景，轻眸识刻确立了**“找得到、读得准、判得清”**的技术攻坚路线：

| 技术维度 | 传统通用方案缺陷 | 轻眸识刻核心创新突破 |
| :--- | :--- | :--- |
| **小目标检测 (找得到)** | 通用检测网络忽略微小打码（占比 < 2%），极易漏检 | 引入 P2 浅层高分辨率特征融合层，结合自适应去反光增强，精准捕获微距打码框 |
| **微型字符识别 (读得准)** | 工业点阵喷墨断笔严重，通用 OCR 字符混淆率高 | 研发针对点阵样式的轻量序列识别网络，搭配标准工业字符字典表 |
| **喷码双向纠错矩阵** | 缺乏针对点阵汉明距离与拓扑空洞的纠错机制 | **核心自研**：基于加权 Levenshtein 动态规划，专项攻克 `O/D ↔ 0`, `I/l/T ↔ 1`, `S/3 ↔ 5`, `B/8 ↔ 8` 混淆 |
| **GB 7718 语义决策树 (判得清)** | 仅框选文字，不具备食品保质期推演能力 | 支持“单一到期日比对时钟”与“生产日期 + 包装直读保质期动态推演”双模式，秒级输出红黄绿安全状态 |
| **样本回流数据飞轮** | 离线单向训练，无法沉淀难例 | 前台与移动端支持一键纠错回流，争议样本自动入库，驱动模型持续进化 |

### 竞争优势分析
- **数据私有与安全保障**：商业平台（如 Roboflow、Ultralytics）要求数据上传公有云，无法满足私有资产保护与现场端侧离线闭环；
- **点阵喷码领域定制**：通用云端 OCR API 缺乏点阵断笔双向纠错与 GB 7718 决策树，识别准确率与结构化解析能力不足；
- **边际成本为零**：自建轻量化推理与训练流水线，一次性研发投入后可支撑长期零成本迭代。

## 三、 预期交付成果与转化价值

对齐大创立项申报书承诺目标：
1. **食品包装日期图像样本库**：沉淀覆盖塑料袋、易拉罐、玻璃瓶、纸盒等多种材质与生活环境的高质量黄金基准样本集；
2. **小目标识别与决策算法集**：产出定位检测、点阵 OCR、双向纠错矩阵与语义决策树算法代码，具备完整的实验对比与消融分析；
3. **Web 原型系统**：完成集成上传识别、Canvas 框选、保质期倒计时卡片与难例回流的交互系统，作为大创中期与结题答辩的核心演示大屏；
4. **实践拓展成果**：支撑软件著作权申报、高水平学科竞赛作品制作与相关学术论文发表。
