## 一、 核心复核结论与研究边界定义

### 1. 核心结论与反伪造红线
食品包装日期在小目标定位后 OCR、日期语法解析、多日期与标示类型区分、视障辅助、移动端轻量级部署以及 OCR 与大语言模型候选选择等方面，**国际与国内均已有直接深入的同题研究**。

> [!CAUTION]
> **学术诚信红线**：严禁在任何申报书、论文或技术文档中出现“国内外对复杂包装日期定位与语义考虑不足”或“填补国内空白/首次提出”等虚假声称。

本项目将“定位 -> OCR -> 日期规则解析”作为成熟的基础工程链路继承，核心学术攻关聚焦于**“非受控实拍包装日期的证据驱动自适应识读与选择性复核”**——旨在攻克未见包装反光磨损、微型点阵断笔、日期类型混淆，并在有限处理成本下实现可靠的低风险拒识与人工复核联动。方法创新成立与否，完全取决于同条件强基线对照、消融实验与独立测试集证据。

## 四、 国家标准法规变化与日期语义定义

### 1. GB 7718—2025 政策实施与影响评估
- **发布与生效时间节点**：国家卫健委官方公告，新标准于 2025 年发布，将于 **2027-03-16 正式实施**；
- **日期痛点强度演进**：新规对包装日期标示位置、字符高度（>=1.8mm）及与背景对比度提出了更高强制要求，并鼓励直接标示“保质期至/最佳食用期”。新规落地后将降低部分“找不到、看不清”的难度，但商超与生活中的旧版包装、进口食品及复杂曲面反光仍将长期存在；
- **数字标签与实物标签**：数字标签并不强制包含逐件生产批次与日期，其实体与数字内容须保持一致，**条形码/二维码不能作为逐件日期的真值替代**。

### 2. 日期起算规则与工程判定边界
依据国家卫健委官方问答第三十六条：
1. **起算口径允许差异**：保质期计算允许从“生产日期当日”或“生产日期次日”起算，工程上直接到期日（EXP）与根据生产日期（MFG）推导的值存在 1 天差异时，**不能未经核验擅自断言标签印制违法或食品过期**；
2. **直接 EXP 独立判定**：在只有可靠直接 EXP 而缺失 MFG 时，系统必须支持独立比较标示期限（date-rules.v2 规范）；
3. **固定临期策略声明**：系统默认采用的 30 天临期预警阈值属于项目工程配置策略，并非国家统一强制法定标准。

## 五、 工业商业方案对比与落地差异

以康耐视（Cognex）为代表的成熟工业 OCR/OCV 视觉系统在固定产线上已广泛应用于生产批号与日期验证。评阅与答辩时须明确本项目与之在工程条件与问题定义上的根本差异：

| 比较维度 | 工业固定产线 OCR/OCV (如 Cognex) | 本项目（《轻眸识刻》移动/手持/桌面场景） |
| :--- | :--- | :--- |
| **成像环境** | 受控强光源、固定工位、恒定焦距、无杂乱反光 | **非受控实拍**：多角度倾斜、复杂货架背景、商超顶光反光、手持抖动虚焦 |
| **包装形态** | 同一批次规格完全单一（如全为同一规格平放纸盒） | **多材质未知形态**：软袋褶皱形变、曲面瓶肩、凹陷易拉罐底、透明塑料微距 |
| **先验模板** | 依赖高精度标定模板（Template Matching）与预设字符字典 | **零模板（Zero-shot/Open-world）**：无预设商品模板，必须自适应定位打码区域 |
| **成本与设备** | 工业级高速相机与专用控制器（成本通常数千至数万元） | **极低成本设备**：普通手机摄像头、通用 Web 摄像头或边缘低算力终端 |

因此，本项目并非简单复现成熟工业方案，而是攻坚在**低成本、无先验模板、非受控复杂实拍条件下的鲁棒性检测识别与低风险拒识复核**。

## 六、 大挑主线攻关方向与实验判据

### 1. 最推荐的研究主线：非受控实拍包装日期的证据驱动自适应识读与选择性复核
在真实未见包装与成像退化条件下，研究如何有效降低“输出合法但内容错误的日期”风险，并在处理预算内动态决策直接输出、多尺度重试、引导补拍或人工复核。

| 研究子方向 | 与已有工作的重叠 | 需要形成的实际差异 | 主要技术风险与代价 |
| :--- | :--- | :--- | :--- |
| **可靠候选选择与选择性复核** | 2020 已有过滤，2022 有解析，2026 已有 OCR+LLM 选择及 unknown | 在相同覆盖率下达成更优的风险—覆盖曲线、误纠正抑制及不确定性度量 | 语法合法不等于真实正确；过度拒识会降低实用价值 |
| **识别需求驱动的自适应定位** | 经典两阶段检测、多尺度与变换校正已有成熟研究 | 字符完整性与整日期识别为目标，自适应缩放/裁剪并测量 p95 延迟与收益 | 仅微调 P2/CLAHE 贡献有限；检测框 IoU 高不代表文字未被截断 |
| **跨图像多面语义关联** | 同图多日期与批号已有解析；工业流水线也有多相机融合 | 探索同一物理包装多视角下的类型消歧、冲突检测与补拍决策 | 多视角采集与关联标注成本极高；不能因未查到直接同名工作即称首创 |

### 2. 主线推进的五阶段实验判据体系

| 阶段 | 核心攻关任务 | 继续推进或调整方向的依据 |
| :--- | :--- | :--- |
| **1. 基线建立** | 在审核后的数据上，严格量化通用 OCR、检测+OCR、结合规则解析的基线成绩 | 明确拆解出定位遗漏、裁剪截断、字符转录错误、类型混淆与置信度不足的分项占比 |
| **2. 失败归因** | 引入真值框（Oracle Box）与真值文本作为诊断上界，统计技术失败 vs 策略拒识 | 验证定位改进是否实质改善最终日期字段；区分视觉感知缺陷与后端语义解析缺陷 |
| **3. 单一改进消融** | 控制其余变量，单独测试某一自适应缩放、置信度门禁或多候选融合算法 | 在同等风险或同等处理时间预算下，测量整日期字段匹配率是否有统计显著提升 |
| **4. 成本与泛化验证** | 在未见包装、新设备手持实拍集上独立盲测，统计 p50/p95 耗时与人工复核率 | 严密确认算法鲁棒性边界，坚决避免把局部特定包装上的指标外推为无条件泛化 |
| **5. 原型链路拉通** | M0 Web 端拉通选图、推理、双重视图呈现与用户纠偏回流 | 测量真实用户场景下的平均任务耗时与防漏看成功率；技术故障严禁伪装为成功 |

### 3. 数据资产遵循与外部独立测试集设计
- **基准资产规模**：主基准受控数据集严格遵循 **1617 张真实原图**（SHA-256 唯一，含 150 张亲审稀缺难例），严格执行 **8:1:1 科学分层切分**（Train 1293 / Val 162 / Test 162）；
- **外部盲测独立性**：测试集严格保持 `group_key` 同源物理隔离，绝对不参与阈值调优、字表拟合、模型选优或量化校准；测试集中必须保留真实难例（弱钢印、模糊断笔、包装褶皱、无日期干扰样本），严禁通过剔除难例粉饰测试成绩。
