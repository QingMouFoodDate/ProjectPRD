---
trigger: model_decision
description: when generate BRD use this format
---

1. 项目背景与动机 (Market Opportunity)
   这部分需要回答：为什么现在要启动这个项目？
   市场现状 / 痛点分析 / 项目目标。

2. 产品商业方案 (Product Proposal)
   产品定位：一句话概括产品是什么。
   核心功能：概括性的功能模块（非技术细节）。
   核心竞争力：差异化优势。

3. 市场竞争分析 (Competitive Analysis)
   直接/间接竞品、SWOT 分析。

4. 商业模式与收益 (Business Value)
   盈利模式、投入产出、预期指标。

5. 资源投入与风险预测 (Resources & Risks)
   人力 / 预算 / 时间；潜在风险与应对方案。

检查清单
   [ ] 目标是否与整体战略一致？
   [ ] 是否定义了衡量成功的方式？
   [ ] 成本与收益是否合理？
   [ ] 是否明确提出需要的支持（人力/钱/授权）？
