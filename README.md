# 轻眸识刻

> **视觉检测模型训练基建 (Training Infrastructure for Vision Detection Models)**
> 面向小团队的 Local-First 数据基建：把「一堆乱图和视频」变成「可复现、可上线的检测模型」。

---

## 项目简介

**轻眸识刻** 是一套自用的视觉模型训练基建。它把模型的完整生命周期——
**数据接入 → 数据管理 → 标注 → 训练 → 流水线 → 部署推理**——收敛进一个单机可跑、
可视化操作的系统里，消除"手搓脚本 + 硬盘拷贝 + Excel 记版本"的原始作业方式。

首个落地任务是**食品包装生产日期识别**（先做日期区域检测，再接入 OCR 读出日期字符串），
但平台本身不与该任务耦合：数据集、标注题型、训练后端三者独立可扩展。

### 核心价值

- **数据不丢、可追溯**: 每一个文件都有归属（哪个数据集、哪个版本），每一个模型都能反查到训练它的数据。
- **标注可作业**: 内置标注器 + 任务派单 + 质检返工，标注质量可统计、可追责。
- **训练可复现**: 数据集版本 + 超参 + 环境镜像三者锁定，同一组合一定产出同一结果。
- **算力可生长**: 起步在笔记本单卡上跑，后续可直接注册远端 GPU 节点，不改业务代码。

### 设计原则

1. **单机优先 (Local-First)**: 一台机器能跑全套；多机是演进，不是前提。
2. **不为规模买单**: 面向 2~3 人团队，不做多租户、不做微服务拆分。
3. **留缝不挖坑**: 只在成本为零的地方留扩展点（如训练后端接口、算子接口），
   不提前实现用不上的通用性。

## 模块说明

| 模块 | 职责 | 核心价值 |
| :--- | :--- | :--- |
| **01_数据采集** | 采集项目与任务定义、移动端现场拍摄、上传与验收 | 零数据冷启动的源头，把"出去拍数据"变成可管理作业 |
| **02_数据导入** | 本地上传、压缩包、标准数据集格式（COCO/YOLO/VOC）、视频抽帧、导入预检 | 让已有的烂数据能干净地进来 |
| **03_数据管理** | 存储桶绑定、数据集与版本、检索筛选、预览统计、导出回收 | 消灭"数据黑洞"，让每个文件可查可追溯 |
| **04_标注中心** | 内置标注器、任务派单、质检返工、AI 预标注、字符转写 | 让标注成为可管理的作业，而不是黑盒 |
| **05_训练平台** | 算力节点、环境镜像、任务调度、指标看板、模型仓库、评估 | 一次点击完成训练，且可复现 |
| **06_流水线** | 十阶段算子化编排、执行记录与重跑 | 把重复劳动固化成模板，一键重跑 |
| **07_部署推理** | 模型服务发布、在线试跑、端侧导出、版本回滚 | 打通"训完的模型怎么用"最后一公里 |
| **08_端接入** | 微信小程序与 RN 客户端的接口契约、开放 API | 让外部业务消费模型能力有据可依 |
| **09_系统管理** | 用户与角色、审计日志、告警中心 | 单机部署下的最小必要治理 |

## 快速开始

### 1. 查阅文档

建议按以下顺序阅读：

1. 阅读 `PLAN.md`: 一页看清产品形态，以及可直接分配的 Issue 清单。
2. 阅读 `SCOPE.md`: 分清哪些是平台内核、哪些是不可省的工程约束、哪些可以先不做。
3. 阅读 `REPOS.md`: 了解四个仓库的分工、跨仓契约与 Issue 拆分顺序。
4. 阅读 `BRD.md`: 了解项目动因与目标。
5. 阅读 `MRD.md`: 了解目标用户与竞品格局。
6. 阅读 `PRD.md`: 查阅功能索引，并深入 `PRD/` 目录下各模块的详细说明。

### 2. 文档规范

详情请参阅 `AGENTS.md`。

- **语言**: 文档内容使用中文，技术术语保留英文。
- **命名**: 遵循项目编号命名法（如 `P0003_视频抽帧`）。
- **流程图**: 复杂逻辑必须使用 Mermaid 绘制。
- **需求格式**: 验收标准必须采用 Gherkin (Given/When/Then) 格式。
