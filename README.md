# 《轻眸识刻》设计与文档中枢

> **项目名称**：轻眸识刻——基于小目标驱动的食品包装日期智能识别系统  
> **组织归属**：`QingMouFoodDate` GitHub 协作组织  
> **本仓定位**：**全域设计与规范中枢**（系统架构设计、需求池、跨仓技术契约与质量标准）

---

## 一、 权威依据

本项目的技术定位、核心承诺与阶段推进，以以下材料为不可动摇的上位依据：

1. **大学生创新训练计划项目立项申报书**（事实基准，核心承诺与验收硬指标以申报书为准）；
2. **大创立项答辩演示材料**（技术主线与展示形态基准）；
3. **“创业+智能设备”项目演进论证材料**（多端演进与远期能力规划参考）。

当规划文档与申报材料存在冲突时：
- 申报承诺与核心研发以申报书为唯一准则；
- 后续扩展方向参考两份论证材料；
- C1~C3 规划属于演进候选，不构成当前既定交付承诺。

---

## 二、 当前研发阶段与定位

当前处于 **C0 核心原型攻坚阶段**，首要目标是跑通“真实样本采集 ➔ 小目标打码检测 ➔ 受限字符 OCR 识别 ➔ 基础标示时效推导 ➔ Web 核心交互原型”的完整单机闭环，并产出规范严谨的基准评测报告。

## 五、 工程协作原则

1. **单一事实来源**：全域技术规范以本仓库为唯一准则，各实现仓仅需关注自身代码与配置；
2. **契约先行**：各端开发前先对齐 `contracts/` 下的 API 与数据结构，保持接口绝对解耦；
3. **质量底线**：严格遵循 `standards/DATA_QUALITY.md`，坚决抵制任何伪造与破坏数据分布的行为。
