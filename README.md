## 二、产品稳定定位与判定边界

系统聚焦食品包装日期智能识别与语义推导，核心边界严格限定为**包装标示状态推导**：

1. **判定对象范围**：系统仅对包装客观印刷文本进行检测与日历规则计算，严禁向用户直接断言食品是否绝对可食用或卫生安全结论；
2. **稳定八仓矩阵**：系统采用 8 个职责明确的独立代码仓库，仓库边界变更须经设计评审；
3. **在线离线严格解耦**：InferPlatform 负责在线 API 与实时推理，TrainPlatform 负责样本治理与训练调度，ModelTrain 负责算法网络攻关。

## 六、工程协作与质量原则

- **架构决议至上**：跨仓代码实现必须对齐 [系统架构.md](系统架构.md) 中的边界划分；
- **模型生命周期隔离**：TrainPlatform 负责治理留痕（`register / validate / release`），InferPlatform 负责在线加载与回滚（`activate / rollback`），发布授权与线上 `active` 状态分别留痕；
- **数据流闭环纪律**：用户纠偏在在线层即时更新会话决策；晋升为离线样本必须经 TrainPlatform 审核，严防标签污染；
- **代码提交规范**：遵循 Conventional Commits 格式 `<emoji> <type>: <简明中文改动>`；
- **资产与代码隔离**：大容量图像与模型文件绝不入 Git 仓库，敏感配置通过受控环境变量注入。
